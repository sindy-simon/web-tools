## 1. Discovery（なぜ作るか）

### 1-1. 経緯 ⬛
当初は「あなたより年上は何人＝人口内の順位」を出す案だったが、**政府統計サイトがこの開発環境から遮断されており
年齢各歳別人口を取得できなかった**（2026-07-24 実測: e-Stat / stat.go.jp とも 403）。
オーナーの指摘「今までも人口データ使ってなかったっけ？」を受けて既存資産を調べたところ、
**`js/lib/birth-year-data.mjs` に 1950〜2024年の出生数の実測値が出典つきで既にあった**。
→ **出生数ベースに切り替え**（2026-07-24 オーナー決定）。外部データの取得が不要になり、待ちがゼロになった。

### 1-2. 仮説 ⬛
- 「日本の出生数は◯人」は AI が答える。**「あなたの年は209万人。今の2.9倍」は自分ごと化した体験**になる。
- 少子化という強い文脈があるので、**自分の年と今を比べた瞬間に驚きが出る**（＝共有されやすい）。

### 1-3. 何が作れて何が作れないか ⬛（重要）

| 出したい数字 | 可否 |
|---|---|
| あなたと同じ年に生まれた人数 | ✅ 出生数そのもの |
| 戦後75年で何番目に多い/少ない年か | ✅ 順位 |
| 今（2023年）と比べて何倍 / 100人あたり何人 | ✅ |
| 同学年の人数 | ✅ ただし**概算**（2年分を日数按分。出生数が年内で一様という近似） |
| 丙午・ベビーブームなどの文脈 | ✅ 既存の `NOTABLE` |
| **あなたより年上は何人 / 日本で上から何番目** | ❌ **作らない** |

❌ の理由: **出生数を足し上げても現在の人口にはならない**（その後の死亡・国際移動が反映されない）。
高齢層ほど実際より多く数えることになり、数字が明確に間違う。
→ やるなら年齢各歳別人口という別の統計が要る。**オーナーが e-Stat から CSV を1つ置いた時点で第2弾として追加可能**。

## 3. Design 🔴

### 3-1. デザインの方向 🔴
既存サイトは実用ツール向けの落ち着いたデザイン（`style.css`: 白カード・青アクセント・最大幅720px）。
本ツールは**結果画面がシェアされる＝それ自体が商品**なので方針が分かれる。

- 案A: 既存デザインに完全に合わせる … 一貫性◎・工数最小。ただし地味でシェアされにくい。
- **案B: 結果部分だけ作り込む**（大きな数字・出生数の推移を示す棒グラフ・強調色）… **推奨**
- 案C: このページだけ別デザイン … インパクト最大だが統一感を損なう。

### 3-2. 結果に出す項目 🔴（順序は根拠つき）
1. **あなたが生まれた年に生まれた赤ちゃんは ◯◯人**（主役の数字）
2. **1日あたり約◯◯人**（スケールを体感させる）
3. **戦後75年で、多い方から◯番目**（順位＝ランキングの切り口）
4. **今（2023年）生まれる100人に対して、あなたの年は◯人**
   ← **％でなく自然頻度**で出す（％は理解されにくい。IDEAS #62 の設計方針）
5. **同学年は約◯◯人**（早生まれ考慮・**概算と明記**）← 日本特化
6. **その年の注記**（丙午・ベビーブーム・1.57ショック等。該当年のみ）
   ＋ 最後に一番強い数字を置く（**Peak-End**：体験の評価は終わりで決まる）

### 3-3. 文言 🔵
断定的に書く（IDEAS #66「診断系は断定的に」）。ただし**推計値・基準日・概算である旨は必ず明記**。

### 3-4. SEO 🔵
**出生数の早見表（1950〜2024の全年）を静的HTMLで出力**する。
（birth-year の失敗＝JS描画でクローラに空divに見える、を回避）

## 4. Build

### 4-1. ロジック ⬛ 完了（2026-07-24）
`js/lib/birth-rank.mjs`（純粋関数）＋ `test/birth-rank.test.mjs`（31件）。
**リポジトリ全体で 271件 green**（既存240件を壊していない）。

| 関数 | 役割 |
|---|---|
| `birthsOf(year)` | その年の出生数 |
| `rankOf(year)` | 多い順・少ない順の順位（同数は同順位） |
| `rankPhrase(year)` | 「多い方から◯番目」か「少ない方から◯番目」か、短い方を選ぶ |
| `schoolYearStart(date)` / `isEarlyBirth(date)` | 学年（4/2〜翌4/1）の判定 |
| `estimateSchoolYearBirths(date)` | 同学年の概算（2年分を日数按分・うるう年考慮） |
| `compareToLatest(year)` | 今との比較（倍率・100人あたり） |
| `birthsPerDay(year)` | 1日あたり出生数 |
| `notableOf(year)` | 丙午等の注記 |
| `summarize(dateOrYear)` | 画面表示用に一式まとめる |

出力例（`summarize("1973-06-01")`）:
```
出生数      : 2,091,983 人（1日あたり 5,731 人）
順位        : 戦後75年で 多い方から 3 番目
今との比較  : 2023年の100人に対して 288 人
同学年(概算): 2,076,527 人（1973年度・早生まれ=false）
注記        : 第2次ベビーブームピーク
```
