SNS文字数チェッカー

投稿文を貼ると、各SNSの文字数上限に収まるかを一括表示。Xは全角2・半角1・URL23の正しい数え方で計算します。

SNS使用上限残り

Xのみ「全角=2・半角=1・URL=一律23」の重み付き、その他は文字数(コードポイント)で計算。入力内容は端末内だけで処理されます。上限値は 2026-06 時点の一般的な公開値で、各SNSの仕様変更で変わることがあります。

X(旧Twitter)の文字数は「280」だが、日本語は「140」— 数え方の仕様

X の投稿上限は公式には「280」です。それなのに日本語だと約140文字しか書けないのは、X が文字を重み付きで数えているからです。ルールは3つだけです。

  • 日本語(ひらがな・カタカナ・漢字)などの全角文字 … 1文字 = 2
  • 半角の英数字・記号・スペース … 1文字 = 1
  • URL … 実際の長さに関係なく一律 23(t.co の短縮リンクに置き換わるため)

つまり「280」は半角基準の数字で、全角だけなら 280÷2=140文字。日本語と英語を混ぜると上限は 140〜280 の間のどこかになり、単純な文字数カウントでは絶対に合いません。これがこのツールを作った理由です。

実例: この投稿は「何文字」なのか

次の投稿文を例に、実際に計算してみます(このページのツールに貼れば同じ結果が出ます)。

新作の記事を公開しました！ポイントは3つ: AI時代の文章術です。 https://mini-tools.net/articles/writing-with-ai-2026-summer-edition #ブログ更新

内訳計算X での重み
全角(日本語・！・。など) 34文字34 × 268
半角(AI・3・#・スペース) 6文字6 × 16
URL(実際は68文字)一律23
X での合計—97 / 280(残り183)
単純な文字数(Threads 等の数え方)—108 文字

同じ文章でも「97」と「108」— 数え方によって1割以上ずれます。長い URL を貼っても23で固定されるのがポイントで、「URL が長いから本文を削る」は X では不要な心配です。逆に Threads や Bluesky は URL も実際の文字数で数えるため、同じ投稿を同時展開するときはこの差で切れます。

海外製カウンターでズレる理由

英語圏の character counter は「1文字=1」で数える前提で作られているため、全角=2 の X ルールや絵文字の扱いが考慮されていないものが多くあります。英語投稿なら問題になりませんが、日本語投稿では「カウンターではOKだったのに投稿画面で溢れる」が起きます。本ツールは日本語投稿を前提に、X だけ重み付き・他は文字数、と数え方を切り替えて表示します。

よくある質問

絵文字は何文字と数えられますか？

X では絵文字は2としてカウントされます(本ツールも2で計算)。Instagram などの単純カウントのサービスでは1文字です。ただし家族の絵文字(👨‍👩‍👧‍👦)のように複数の絵文字を結合したものは、サービスによって数え方が分かれる境界ケースです。

有料プラン(X Premium)の長文投稿には対応していますか？

本ツールの上限表示は無料アカウントの280(重み付き)を基準にしています。Premium の長文投稿(最大25,000字)を使う場合は、残り文字数はマイナス表示になりますが使用量の計算自体は正確です。
